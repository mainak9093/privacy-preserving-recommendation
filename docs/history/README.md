# The project's working history

These are the planning documents the project actually used, kept so that anyone can see how the work was scoped, scheduled and
revised. **They are a record and not a description of the current system.** Each was right on its date, and many statements in them
were later overtaken. Where one disagrees with [`docs/`](../README.md) or the [final report](../../report/final.pdf), those win.

| Document | What it is | Covers |
|---|---|---|
| [`REQUIREMENTS.md`](REQUIREMENTS.md) | The scope contract: functionality, deliverables `D1` to `D9`, baselines, non-goals | Written August, with later amendments |
| [`PHASES.md`](PHASES.md) | The schedule, with the status and evidence for every task through to the final submission | The whole project |
| [`MIDTERM_PLAN.md`](MIDTERM_PLAN.md) | The plan for the stretch before the mid-term | 3 to 12 September |
| [`HANDOVER.md`](HANDOVER.md) | A status and handover note for the team before the mid-term | 9 to 11 September |
| [`contributions.md`](contributions.md) | The working log. It stops at 11 September and is incomplete, as its own notes say | August to September |

The original design draft and its log of decisions is in [`design/ARCHITECTURE-draft-v1.md`](../../design/ARCHITECTURE-draft-v1.md).

Remarks about course marks and about other groups were trimmed from these documents when the repository was tidied for readers. The
files are otherwise as they were, and the untrimmed versions are at tag
[`v1.0-final`](https://github.com/mainak9093/privacy-preserving-recommendation/tree/v1.0-final).
